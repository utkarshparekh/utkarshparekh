# Utkarsh Parekh — Portfolio

A responsive, interactive portfolio site for [@utkarshparekh](https://github.com/utkarshparekh), built as a static site with plain HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish the site at `https://utkarshparekh.github.io/utkarshparekh/`.

The project cards and descriptions are curated from public repository information; update `index.html` as your work changes. The email link is intentionally generic until a preferred contact address is available.
